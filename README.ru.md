## Возможности

| Что | Как это работает |
| --- | --- |
| **Бытовые вопросы на равных с научными** | Рукоделие, ремонт, хобби, покупки разбираются так же тщательно, как наука, но без академического тона |
| **Разбор «до атомов»** | Если источник советует метод, инструмент или материал, скилл отдельно выясняет: что это, почему подходит, что нужно заранее, какие шаги и как проверить результат |
| **Уровни глубины** | Быстро / Стандарт / Глубоко / Исчерпывающе, у каждого свой примерный бюджет поисков |
| **Широкий поиск на разных языках** | Сайты, Reddit, YouTube, Telegram, TikTok, Instagram, Facebook, форумы, научные базы, архивы |
| **Реестр источников** | У каждого источника есть тип, уровень доступа, дата, «семейство» и конфликт интересов. Ссылаться можно только на открытые страницы из реестра |
| **Проверка по SIFT** | Незнакомые источники проверяются извне. Для быстро меняющихся фактов проверяется свежесть. Ни один источник не должен тащить весь вывод на себе |
| **Цикл критики** | Черновик читают скептик, новичок, эксперт и читатель из другой страны. Найденные дыры превращаются в новые поиски |
| **Уверенность по каждому выводу** | Высокая / средняя / низкая с объяснением почему, сильнейший контраргумент в спорных местах, без поддакивания |
| **Таблица сравнения** | Варианты × критерии, неизвестное помечено как неизвестное, решающий критерий назван явно |
| **Честная заметка о покрытии** | Что искали, что было недоступно, что не пробовали и изменит ли дальнейший поиск ответ |

### Требования

| Возможность агента | Статус | Зачем |
| --- | --- | --- |
| Веб-поиск | **обязательно** | Находить источники |
| Чтение страниц | желательно | Читать оригиналы и превью каналов `t.me/s` |
| Текущая дата | желательно | Проверять свежесть, ставить верный год в запросах |
| Управление браузером | по желанию | Поиск внутри соцсетей, Telegram Web, институциональный доступ |
| Поиск картинок | по желанию | Наглядные примеры для рукоделия и творческих задач |
| Выполнение кода | по желанию | Расчёты, проверка кода, сохранение заметок |
| Субагенты | по желанию | Параллельный поиск на уровнях «Глубоко» и «Исчерпывающе» |

Если чего-то не хватает, скилл работает с тем, что есть, и пишет об ограничениях в заметке о покрытии.

## Быстрый старт

### Установка

**Claude Code**

```bash
# для всех проектов
git clone https://github.com/empty-complete/research-brief.git ~/.claude/skills/research-brief

# или только для текущего проекта
git clone https://github.com/empty-complete/research-brief.git .claude/skills/research-brief
```

**Приложения Claude (claude.ai, десктоп, мобильное)**

```bash
git clone https://github.com/empty-complete/research-brief.git
zip -r research-brief.zip research-brief -x "research-brief/.git/*"
```

Затем откройте **Customize → Skills → + → Create skill → Upload a skill** и загрузите архив. В архиве должна быть папка `research-brief/`, а `SKILL.md` должен лежать прямо в ней. Выполнение кода должно быть включено, подробности в [справке](https://support.claude.com/en/articles/12512180-use-skills-in-claude).

**OpenAI Codex CLI**

```bash
git clone https://github.com/empty-complete/research-brief.git ~/.codex/skills/research-brief
```

**Другие агенты** (Cursor, Gemini CLI, OpenClaw и свои). Если агент поддерживает `SKILL.md`, папка подходит как есть. Если нет, добавьте в системный промпт или `AGENTS.md`:

> Для исследовательских вопросов следуй `research-brief/SKILL.md` и читай справочные файлы, на которые он ссылается.

### 1. Заполните профиль (по желанию)

Откройте [`references/user-profile.md`](references/user-profile.md) и укажите то, что нужно. Всё остальное возьмётся по умолчанию:

```text
Output language: Russian
Extra search languages: Russian, English
Mandatory channels: Reddit, YouTube, Telegram
Signed-in services: YouTube и Telegram Web в браузере агента (только чтение)
Institutional access: сеть университета — ScienceDirect, Springer
Country for prices/availability: Россия
```

Пароли, ключи, куки и токены в профиль не пишите.

### 2. Задайте вопрос

```text
/research-brief как сделать свечу в виде булочки с корицей? я новичок
```

Можно и просто спросить: агент сам подхватит скилл по описанию.

### 3. Готово!

Сначала вы получите короткую сводку со ссылками и уровнем уверенности. Дальше, в зависимости от вопроса, идёт пошаговое руководство, сравнительная таблица или подробный отчёт.

## Использование

### Режимы

| Режим | Когда включается | Что получаете |
| --- | --- | --- |
| Бытовой и творческий | Рукоделие, ремонт, хозяйство, хобби, эстетика | Пошаговое руководство с материалами, контрольными точками и решением проблем |
| Технический | Программирование и инженерия | Рекомендация с версиями, минимальный пример, подводные камни, альтернативы |
| Научный | Вопросы, где нужна научная литература | Таблица доказательств, выводы по подвопросам, ограничения, список литературы |
| Сравнение и выбор | Нужно выбрать из вариантов | Таблица «варианты × критерии» и обоснованный выбор |

### Браузер и входы в сервисы

Если агент управляет вашим браузером (Claude in Chrome, встроенный браузер, Playwright с вашим профилем), перечислите в профиле сервисы, в которые вы вошли. Скилл использует их **только для чтения**: не пишет, не ставит реакции, не вступает в каналы и группы, ничего не покупает и не меняет настройки.

### Telegram

Работает без настройки. Публичные каналы читаются через `https://t.me/s/<канал>` (с `?q=` для поиска внутри канала), а искать их можно в [TGStat](https://tgstat.ru/). Если в браузере агента выполнен вход в Telegram Web, добавляются глобальный поиск и комментарии.

Telegram MCP на Telethon подключать не обязательно. У таких серверов обычно полный доступ к аккаунту, включая отправку и удаление. Им нужны API-ключи с my.telegram.org, а автоматизация через личный аккаунт может привести к ограничениям. Скилл вызывает у них только инструменты поиска и чтения.
